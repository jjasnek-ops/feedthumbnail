QUESTIONS

Thumbnail downloader FAQ

Can I submit several links?

Yes. Put one YouTube link or video ID on each line. Each valid line gets its own result group.

Why is a larger file missing?

YouTube does not expose every filename for every video. The page removes a card when its image does not load, so it does not present a broken size as available.

How does a Shorts thumbnail work?

Paste the Shorts URL on its own line. The browser uses that video's ID with the direct YouTube image host and reports the dimensions of each file that loads. It does not create a separate portrait crop.

Does this page upload my links or images?

No. The page parses links in this browser and requests the direct image URL from YouTube's image host. It has no account, server-side form, or daily limit.

How do I preview a downloaded image?

Choose Preview in tool on a result card. The image is converted inside this browser and handed to the homepage preview without uploading it to this site.

Are the size names invented?

No. The cards use the exact YouTube CDN filenames tested for this tool, and the pixel dimensions are read from each image after it loads.
