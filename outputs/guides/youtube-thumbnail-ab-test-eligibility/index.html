YOUTUBE THUMBNAIL SIZE · A/B TEST CHECK

Why can’t I A/B test a YouTube thumbnail?

A correct YouTube thumbnail size is not enough to make an A/B test available. The current YouTube Help page lists separate eligibility requirements: the feature is available through YouTube Studio on a computer, advanced features must be enabled, and some video types and content settings are excluded. Prepare the image locally, but diagnose access at the channel and video level.

Official source: Test & compare thumbnails & titles - YouTube Help, reviewed 2026-10-15.

THE CURRENT ELIGIBILITY LIST

What does YouTube require before an A/B test can run?

The current official A/B-testing page does not reduce eligibility to an image dimension. It says the feature is currently available on computers through YouTube Studio, requires advanced features to be enabled, and excludes Shorts, Scheduled Lives, and Premiere videos at this time. It separately says that Live Archives can be tested and that a Premiere becomes eligible only after it ends and converts to a long-form video.

“This feature is currently only available on computers through YouTube Studio.”

— YouTube Help, Test & compare thumbnails & titles

The page also lists content restrictions. Videos made for kids, mature audiences, or private videos cannot use the feature. Its age-restriction note adds a specific warning about losing feature access when age-restricted content is uploaded without the corresponding setting. These are account and video-state checks, not thumbnail-canvas checks.

THREE DIFFERENT CHECKS

Which eligibility check is failing?

When the testing control is missing, the fastest useful diagnosis is to separate the levels. A local tool can show what happened to an image. YouTube Studio decides whether the channel and video can use the feature. The official Help page is the source for that product-level decision.

Channel accessAdvanced features must be enabled before the feature is eligible.
Video typeShorts, Scheduled Lives, and Premiere videos are excluded under the checked rule.
Video settingsMade-for-kids, mature-audience, and private videos are excluded.

A missing control therefore does not prove that the image is too small. Conversely, a clean local export does not prove that the control should appear. Use the product’s eligibility list first, then investigate the image-specific requirements separately.

A PRACTICAL ACCESS CHECK

How should you troubleshoot a missing A/B-test control?

  1. Prepare the image separately. Open the thumbnail resizer or the local feed preview, choose the image, and inspect the crop and title placement.
  2. Use a computer for the product check. The official page says the feature is currently available through YouTube Studio on a computer. Do not treat a mobile-only view as proof that the feature is unavailable everywhere.
  3. Check advanced features. The official eligibility list says advanced features must be enabled. Follow YouTube’s own access instructions rather than guessing from the thumbnail file.
  4. Check the video type. Exclude Shorts, Scheduled Lives, and active Premiere videos under the current rule. A Live Archive is treated differently on the official page.
  5. Check the video settings. Made-for-kids, mature-audience, and private videos are listed as ineligible. Resolve the actual setting shown in YouTube Studio before changing the image.

This workflow combines the current official eligibility list with reproducible first-party local behavior. It does not access YouTube Studio, change settings, or promise that a creator will receive the feature.

QUESTIONS

YouTube thumbnail size and A/B-test eligibility questions

Does YouTube thumbnail size make an A/B test available?

No. Thumbnail preparation and A/B-test eligibility are separate checks. The current official page lists channel, device, video-type, and content-setting requirements.

Can I run the A/B test from a phone?

The checked official page says the feature is currently available on computers through YouTube Studio.

Do I need advanced features enabled?

Yes. The current eligibility list says advanced features must be enabled to be eligible.

The checked page says Shorts, Scheduled Lives, and Premiere videos cannot be A/B tested at this time. It treats Live Archives separately.
